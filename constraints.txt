# Transitive dependencies, locked to what the published v1.2.0 resolved to.
# Generated from the release CycloneDX SBOMs of all FOUR build targets.
# Do not hand-edit.
#
#     pip install -r requirements.txt -c constraints.txt
#
# The nine direct dependencies are pinned in requirements.txt; this file locks
# everything they drag in, so the whole graph is fixed and not only the names
# we chose deliberately.
#
# It is the union of windows-x64, linux-x64, macos-arm64 AND macos-x64. All
# four matter. An earlier version of this file was built from the first three,
# and the macos-x64 build then failed with ResolutionImpossible, because:
#
#     onnxruntime is 1.29.0 everywhere except Intel macOS, where the newest
#     available wheel is 1.23.2
#
# so pinning the arm64 version made the Intel build unsatisfiable. Where a
# package genuinely differs by platform it is written twice with environment
# markers rather than one being picked. Intel macOS also pulls coloredlogs,
# humanfriendly, mpmath and sympy, which the older onnxruntime needs and the
# newer one does not.
#
# Constraints on packages that are not installed are ignored by pip, so
# carrying every platform costs nothing and is the only way the lock is
# complete everywhere.
#
# PyPI libraries only. The SBOM also lists CPython itself, as type application
# with a pkg:generic purl. It is the interpreter the bundle ships, not
# something pip resolves, and including it fails any install with
# "No matching distribution found for cpython".
