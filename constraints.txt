# resolve to the same set -- colorama is Windows-only, python-xlib is Linux-only,

# installed are ignored by pip, so carrying all three costs nothing and is the
# only way the lock is complete everywhere.
#

# with a pkg:generic purl. It is the interpreter the bundle ships rather than
# something pip can resolve, and including it breaks both pip-audit and any
# plain -r install with "No matching distribution found for cpython".
#

# what makes one shared file possible. Re-check that when bumping.
